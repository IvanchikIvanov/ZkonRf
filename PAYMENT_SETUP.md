# Настройка платежей

## Telegram Stars

Telegram Stars работает автоматически, дополнительных настроек не требуется. Используется токен бота из `TELEGRAM_BOT_TOKEN`.

### Как это работает:
1. Пользователь нажимает `/subscribe`
2. Выбирает оплату через Telegram Stars
3. Оплачивает через встроенный интерфейс Telegram
4. Подписка активируется автоматически

## ЮKassa

### 1. Регистрация в ЮKassa

1. Зарегистрируйтесь на https://yookassa.ru/
2. Создайте магазин (требуется ИП или ООО)
3. Получите:
   - **Shop ID** (идентификатор магазина)
   - **Secret Key** (секретный ключ)

### 2. Настройка переменных окружения

Добавьте в `.env`:

```env
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_secret_key
YOOKASSA_TEST_MODE=true  # true для тестов, false для продакшена
WEBHOOK_URL=https://yourdomain.com/webhook/yookassa
```

### 3. Настройка вебхуков

В личном кабинете ЮKassa:
1. Перейдите в "Настройки" → "HTTP-уведомления"
2. Добавьте URL: `https://yourdomain.com/webhook/yookassa`
3. Выберите события: `payment.succeeded`

### 4. Автоматический запуск веб-сервера

Веб-сервер для обработки вебхуков запускается **автоматически** вместе с ботом в одном процессе, если ЮKassa настроена. Дополнительных действий не требуется.

**Важно:** 
- Веб-сервер должен быть доступен из интернета по HTTPS для работы вебхуков
- Порт по умолчанию: `8080` (можно изменить через `WEBHOOK_PORT` в `.env`)
- Убедитесь, что порт открыт в файрволе и проксирован через HTTPS (например, через nginx)

### 5. Тестирование

1. Установите `YOOKASSA_TEST_MODE=true`
2. Используйте тестовые карты:
   - Успешный платеж: `5555 5555 5555 4444`
   - CVV: любой 3-значный код
   - Срок действия: любая будущая дата

## Настройка лимитов

В `.env`:

```env
FREE_REQUESTS_PER_DAY=3  # Количество бесплатных запросов в день
SUBSCRIPTION_PRICE_STARS=100  # Цена в Telegram Stars
SUBSCRIPTION_PRICE_YOOKASSA=299  # Цена в рублях
```

## Команды бота

- `/subscribe` - Оформить подписку
- `/start` - Начать работу
- `/help` - Справка
- `/stats` - Статистика базы данных

## Проверка подписки

Бот автоматически проверяет подписку перед обработкой каждого запроса:
- Подписчики: неограниченное количество запросов
- Бесплатные пользователи: ограничение по `FREE_REQUESTS_PER_DAY`

## Хранение данных

Подписки хранятся в Redis:
- Ключ: `subscription:{user_id}`
- TTL: 30 дней (автоматическое удаление после истечения)

Счетчики запросов:
- Ключ: `requests:{user_id}:{date}`
- TTL: 24 часа (сброс каждый день)
