# Настройка платежей

## Telegram Stars

Telegram Stars работает автоматически, дополнительных настроек не требуется. Используется токен бота из `TELEGRAM_BOT_TOKEN`.

### Как это работает:
1. Пользователь нажимает `/subscribe`
2. Выбирает оплату через Telegram Stars
3. Оплачивает через встроенный интерфейс Telegram
4. Подписка активируется автоматически

## ЮKassa

### 1. Регистрация в ЮKassa

1. Зарегистрируйтесь на https://yookassa.ru/
2. Создайте магазин (требуется ИП или ООО)
3. Получите:
   - **Shop ID** (идентификатор магазина)
   - **Secret Key** (секретный ключ)

### 2. Настройка переменных окружения

Добавьте в `.env`:

```env
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_secret_key
YOOKASSA_TEST_MODE=true  # true для тестов, false для продакшена
# Пока работает бот: опрос Redis и API ЮKassa (рекомендуется 60–300 сек)
YOOKASSA_POLL_INTERVAL_SECONDS=120
```

Публичный URL и HTTP-уведомления в личном кабинете ЮKassa **настраивать не обязательно**: подтверждение оплаты идёт через периодический запрос `Payment.find_one` по номеру платежа (ключи `payment:*` в Redis создаются при выдаче ссылки на оплату).

### 3. Требования

- **Redis** — для ключей `payment:*` и идемпотентности.
- Бот должен быть **запущен**, пока пользователь может оплатить и ожидать подписку (опрос крутится в фоне того же процесса).

### 4. Тестирование

1. Установите `YOOKASSA_TEST_MODE=true`
2. Используйте тестовые карты:
   - Успешный платеж: `5555 5555 5555 4444`
   - CVV: любой 3-значный код
   - Срок действия: любая будущая дата

## Настройка лимитов

В `.env`:

```env
FREE_REQUESTS_PER_DAY=3  # Количество бесплатных запросов в день
SUBSCRIPTION_PRICE_STARS_1MONTH=100  # Цена в Telegram Stars за 1 мес.
SUBSCRIPTION_PRICE_YOOKASSA_1MONTH=100  # Цена в рублях за 1 мес.
```

## Команды бота

- `/subscribe` - Оформить подписку
- `/start` - Начать работу
- `/help` - Справка
- `/stats` - Статистика базы данных

## Проверка подписки

Бот автоматически проверяет подписку перед обработкой каждого запроса:
- Подписчики: неограниченное количество запросов
- Бесплатные пользователи: ограничение по `FREE_REQUESTS_PER_DAY`

## Хранение данных

Подписки и лимиты пользователей — в SQLite (`users.db` рядом с каталогом данных).

Счетчики и кеш — в Redis (при наличии подключения).
