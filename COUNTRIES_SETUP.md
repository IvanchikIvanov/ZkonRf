# Настройка кодексов для разных стран

## Поддерживаемые страны

Бот поддерживает кодексы следующих стран:

- 🇷🇺 **Россия** (ru) - по умолчанию
- 🇰🇿 **Казахстан** (kz)
- 🇦🇲 **Армения** (am)
- 🇧🇾 **Беларусь** (by)
- 🇹🇯 **Таджикистан** (tj)
- 🇺🇿 **Узбекистан** (uz)
- 🇦🇿 **Азербайджан** (az)

## Структура папок

Рекомендуемая структура для организации кодексов по странам:

```
data/codexes/
├── ru/              # Россия
│   ├── koap.txt
│   ├── uk.txt
│   └── gk.txt
├── kz/              # Казахстан
│   ├── koap.txt
│   └── ugolovnyi.txt
├── am/              # Армения
│   └── ...
├── by/              # Беларусь
│   └── ...
├── tj/              # Таджикистан
│   └── ...
├── uz/              # Узбекистан
│   └── ...
└── az/              # Азербайджан
    └── ...
```

## Альтернативная структура

Если не хотите использовать подпапки, можно использовать префикс в имени файла:

```
data/codexes/
├── ru_koap.txt          # Россия
├── ru_uk.txt
├── kz_koap.txt          # Казахстан
├── kz_ugolovnyi.txt
└── ...
```

## Формат файлов кодексов

Каждая статья должна начинаться с "Статья X.":

```
Статья 1. Текст первой статьи...

Статья 2. Текст второй статьи...

Статья 3. Текст третьей статьи...
```

**Поддерживаемые форматы:**
- `.txt` - текстовые файлы
- `.md` - Markdown файлы
- `.odt` - OpenDocument Text
- `.docx` - Microsoft Word документы

## Индексация кодексов

После размещения файлов кодексов запустите индексацию:

```bash
python -m scripts.process_codexes
```

Скрипт автоматически:
- Определит страну из структуры папок или имени файла
- Извлечет все статьи
- Сгенерирует embeddings
- Сохранит в векторную БД с метаданными о стране

## Использование в боте

### Выбор страны

Пользователи могут выбрать страну для поиска:

```
/countries          # Показать список доступных стран
/country kz         # Выбрать Казахстан
/country            # Показать текущую страну и инструкцию
```

### Поиск

После выбора страны поиск будет выполняться только в кодексах выбранной страны. Если страна не выбрана (по умолчанию Россия), поиск выполняется по всем странам.

## Метаданные статей

Каждая статья в базе данных содержит:
- `country` - код страны (ru, kz, am, by, tj, uz, az)
- `codex_name` - название кодекса
- `article_number` - номер статьи
- `link` - ссылка на статью (опционально)

## ID статей

Формат ID статей: `{country}_{codex_name}_article_{number}`

Примеры:
- `ru_koap_article_5.27` - Россия, КоАП, статья 5.27
- `kz_koap_article_5.27` - Казахстан, КоАП, статья 5.27

Это позволяет различать статьи с одинаковыми номерами из разных стран.

## Обратная совместимость

Старые файлы кодексов без указания страны будут автоматически определяться как кодексы России (ru).
